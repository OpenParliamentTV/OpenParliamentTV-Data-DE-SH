# OpenParliamentTV-Data-DE-SH
Open Parliament TV Data Repository for the Schleswig-Holstein state parliament (Landtag Schleswig-Holstein)

> **Status:** in development

## Pipeline

This data is generated by the `DE-SH` parliament implementation in
[OpenParliamentTV-Tools](https://github.com/OpenParliamentTV/OpenParliamentTV-Tools):
[`optv/parliaments/DE-SH`](https://github.com/OpenParliamentTV/OpenParliamentTV-Tools/blob/main/optv/parliaments/DE-SH).
